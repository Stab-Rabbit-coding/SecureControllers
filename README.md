# SecureControllers
unmanned system controllers with security baked in. 

These started as the avionics suite for the Serenity UAV, but aren't limited to that.

1. EMI-Hardened Beagle Capes

    * PocketBeagle2-I Secure Flight Controller
    * PocketBeagle2-I Secure Communications
    * PocketBeagle2-I Sub-Gigahertz Trustworthy Transceiver


2. Trustworthy Sensor R-PI HATs

2. Trustworthy Gateway devices

    * Stackable CAN+RS-485 peripherals Gateway for GPIO/SPI/TTL/ADC/DAC/UART with a TPM.

3. Trustworthy Final Control Elements

    * 50A ESC
    * digital servo
    * Camera/Laser pod
    * Power Distribution Board
