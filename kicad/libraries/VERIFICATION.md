## Findings against existing board copies

### 749010012A

- Observer uses an 8-pin symbol with invented PHY_/LINE_ pin names and an 8-pad footprint -- does not match the 16-lead part.
- Wurth datasheet p.1: not intended for aviation use unless Wurth is informed before design-in.

### ESD101-B1-02ELS

- TACCO/Commo used RCLAMP0502B (deprecated per owner 2026-09-26).
- RClamp0504FA proposed as successor is a 3 pF USB-class array -- unsuitable for 50-ohm antenna feeds.

### HI-1573PCI

- Pilot/TACCO copies type the exposed pad power_in; datasheet says the heat sink is electrically isolated -> passive.

### ISOW1044BDFMR

- Pilot/TACCO/Flight Engineer copies type every pin passive -- ERC driver checks disabled.
- Observer/gateway copy is named Observer_ISOW1044BDFMR -- board-scoped name.

### ISOW1412DFMR

- Gateway/Observer copy is named GW_ISOW1412 -- board-scoped name; Pilot copy types every pin passive.

### LMV331

- Commo RSSI_CMP (Value "LMV331 RSSI Carrier-Detect") correctly uses this 5-pin pinout.
- Commo's OTHER SOT-23-5 comparator, ref "RX Demod" (Value "LM393 Comparator RX-AFSK Demodulator"), is mislabeled: real TI LM393 is a DUAL comparator with no 5-pin package (SOIC-8/VSSOP-8/SOT-23-8/TSSOP-8/WSON-8 only per the same datasheet's Device Information table). The drawn symbol has only 5 pins (AFSK_IN, +3V3, COMP_IN, GND, GND) with NO output pin at all -- pin 5 is wired to GND instead of an output net. This is almost certainly meant to be a single comparator (LMV331-class, same as RSSI_CMP) with pin 5 miswired. NOT fixed this session -- flagged per root AGENTS.md (no fabricated pin assignments); needs the intended output net traced before relinking.

### MBRD1045CT

- Note for the fetching agent: this is the Good-Ark MBRD1045CT (Schottky rectifier); an ON Semi/Vishay part of a similar name (MBRD1035/1045) may have a different pinout -- this entry is verified against the Good-Ark datasheet specifically, matching the MPN actually used in Flight Engineer (D_OR1/D_OR2).

### PRTR5V0U2X

- Pilot TVS-CAN/TVS-RS485, Flight Engineer D_I2C, Commo ANT TVS and Observer (5x) use a SOT-363 6-pad footprint -- wrong package.
- Pilot, TACCO and Flight Engineer put the bus line on pin 1 and ground on pin 2; datasheet pin 1 is GND and pin 2 is I/O1.

### SLB9672

- Commo footprint uses EP3.45x3.45 -- datasheet EP is 3.6 x 3.6 mm.
- Gateway/Observer copy lists pin 10 as NCI; datasheet Table 13 is NCI/VDD.

### SN74LVC1G3157DRY

- Commo MUX1 (SN74LVC1G157 symbol) had +3V3 on pin 4 and MODE_SEL on pin 5 -- matches neither the '157 nor the '3157 pinout; rewired on the '3157 (owner decision 2026-09-26).

### TLV62569DBV

- Gateway/Observer symbol puts FB on pin 5 and PG on pin 6 on a SOT-23-6 footprint -- matches no TI variant (TLV62569PDDC has PG=5, FB=6).
- Flight Engineer places TLV62569DBVR on a 3-pad SOT-23 footprint.

### TLV75725PDBV

- Observer copy omits NC pin 4.

### TPS62933DRLR

- Pilot/TACCO copies name pin 7 SS/PG; for the TPS62933DRLR ordering code it is SS only.
