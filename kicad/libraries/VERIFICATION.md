## Findings against existing board copies

### 749010012A

- Observer uses an 8-pin symbol with invented PHY_/LINE_ pin names and an 8-pad footprint -- does not match the 16-lead part.
- Wurth datasheet p.1: not intended for aviation use unless Wurth is informed before design-in.

### HI-1573PCI

- Pilot/TACCO copies type the exposed pad power_in; datasheet says the heat sink is electrically isolated -> passive.

### ISOW1044BDFMR

- Pilot/TACCO/Flight Engineer copies type every pin passive -- ERC driver checks disabled.
- Observer/gateway copy is named Observer_ISOW1044BDFMR -- board-scoped name.

### ISOW1412DFMR

- Gateway/Observer copy is named GW_ISOW1412 -- board-scoped name; Pilot copy types every pin passive.

### PRTR5V0U2X

- Pilot TVS-CAN/TVS-RS485, Flight Engineer D_I2C, Commo ANT TVS and Observer (5x) use a SOT-363 6-pad footprint -- wrong package.
- Pilot, TACCO and Flight Engineer put the bus line on pin 1 and ground on pin 2; datasheet pin 1 is GND and pin 2 is I/O1.

### SLB9672

- Commo footprint uses EP3.45x3.45 -- datasheet EP is 3.6 x 3.6 mm.
- Gateway/Observer copy lists pin 10 as NCI; datasheet Table 13 is NCI/VDD.

### TLV62569DBV

- Gateway/Observer symbol puts FB on pin 5 and PG on pin 6 on a SOT-23-6 footprint -- matches no TI variant (TLV62569PDDC has PG=5, FB=6).
- Flight Engineer places TLV62569DBVR on a 3-pad SOT-23 footprint.

### TLV75725PDBV

- Observer copy omits NC pin 4.

### TPS62933DRLR

- Pilot/TACCO copies name pin 7 SS/PG; for the TPS62933DRLR ordering code it is SS only.
